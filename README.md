# 《智械學園：AI 覺醒調查錄》
### Cyber Academy: The AI Awakening

> 一款專為台灣中小學生量身打造的 **2D 視覺小說 / RPG 對話解謎教育遊戲**。
> 深度結合 **台灣 108 課綱科技領域（國小高年級至國中）資訊科技核心素養**，引導玩家透過生活化情境與推理對話，破除常見科技迷思，建立堅實的運算思維與數位公民素養。

---

## 🌟 遊戲核心特色

- **零相依、開箱即玩**：純前端原生技術架構（HTML5、CSS3、Vanilla JavaScript、Web Audio API），無須安裝 Node.js 或後端伺服器，直接以瀏覽器開啟 `index.html` 即可流暢遊玩。
- **雙軌素養數值系統**：
  - **🧠 邏輯值（Logic）**：回答符合科學與演算法原理（特徵提取、機器學習生命週期、GIGO 等）時提升。
  - **⚖️ 倫理值（Ethics）**：在面對隱私權、深偽假訊息、智慧財產權與人機邊界議題時做出負責任的決定時提升。
- **AI 百科圖鑑與關鍵證物系統**：
  - 收錄 9 大人工智慧核心名詞（電腦視覺、特徵提取、規則驅動、機器學習、GIGO、資料偏見、生成式 AI、AI 幻覺、深偽技術）。
  - 調查過程中可搜集關鍵證物（校狗人臉誤判紀錄、5000 筆香菜珍奶假好評、1895 年太空總署假公文、數位素養認證徽章），於推理與辯論中出示證物。
- **108 課綱隨堂情境評量**：
  - 內建 20 題生活化評量題庫。每章調查結束時，由林老師隨機抽取 2 題進行即時評量，並在答題後提供「艾瑪學姊的溫柔引導提示（鷹架提問）」。
- **無懲罰容錯引導機制**：
  - 選錯對話不會導致 Game Over，而是觸發 NPC 的幽默吐槽與艾瑪學姊的觀念拆解，鼓勵學生從試錯中學習。
- **雙軌音訊系統（實體音訊 + Web Audio API 程序化合成備援）**：
  - 內建 9 款實體音效（.mp3 / .wav），並配備原生 Web Audio API 合成器，即使檔案離線亦能透過瀏覽器原生振盪器即時發聲。
  - 支援打字機語音頻率調製（不同角色擁有不同發聲頻率）。
- **日系清新校園科技風視覺**：
  - 透過 `colab-text-to-image` Skill 在 Google Colab GPU 上繪製，包含 5 張 16:9 背景、8 款動態表情立繪（BiRefNet 自動去背透明 PNG）與 4 款道具圖示。
- **LocalStorage 本機自動存檔**：支援斷點續玩、數值紀錄與一鍵重置。

## 📖 故事世界觀與登場角色

### 故事背景
西元 2035 年，台灣「新星智慧實驗中學」。校園內的大小事務均由中央 AI 系統「小智（Zhi-Bot）」協助管理。
開學第一天，校園廣播突然傳出錯亂訊息：人臉辨識閘門把校狗當成校長熱烈歡迎、營養午餐被強制替換成「香菜珍珠奶茶」、甚至全校廣播要求「取消體育課改為發呆課」！
玩家扮演「校園科技糾察隊」新進實習生，隨身攜帶「AI 邏輯分析儀」，與夥伴們深入校園各個角落，調查異常背後的真相！

## 🚀 如何執行與遊玩

本專案為純前端單頁遊戲，不需要配置任何伺服器環境或資料庫：

### 方法一：直接點擊開啟（最快）
在作業系統的檔案總管或 Finder 中，直接連按兩下開啟 **`index.html`**，即可直接在預設瀏覽器（Chrome、Edge、Safari、Firefox）中開始遊玩！

### 方法二：使用 Python 本機伺服器
若希望以標準 Web Server 形式運行：
```bash
# 切換至專案根目錄
cd rpg-game-test

# 啟動本機簡易伺服器
python3 -m http.server 8080
```
開啟瀏覽器前往：`http://localhost:8080`

### 方法三：使用 VS Code Live Server
若使用 Visual Studio Code，右鍵點擊 `index.html` 並選擇 **「Open with Live Server」** 即可。

## 🎨 美術與音效素材產生工具

專案內建了完整的自動化生成腳本，可供後續擴充素材或重繪：

### 1. 視覺圖片生成 (`colab-text-to-image`)
本專案與 Google Colab GPU 整合，使用 SDXL-Turbo / Z-Image-Turbo 與 BiRefNet 自動去背：
- 提示詞規格書：[docs/美術圖片素材清單與AI繪圖提示詞.md](docs/美術圖片素材清單與AI繪圖提示詞.md)
- 批次生成執行檔：[scripts/batch_generate.py](scripts/batch_generate.py)
```bash
python3 scripts/batch_generate.py
```

### 2. 開源音效與音樂
- 試聽與調音面板：直接於瀏覽器開啟 [audio_preview.html](audio_preview.html) 測試各項音效與打字音。
- 完整音訊下載腳本：
```bash
bash scripts/download_audio.sh
```
